## 🚀 Sobre la aplicación

**FotoApp** es una aplicación móvil diseñada para facilitar el registro de evidencias visuales en campo. Permite capturar fotografías, asociarlas con coordenadas geográficas, agregar comentarios y consultar las evidencias almacenadas desde una galería integrada.

## ✨ Características principales

- 🔐 **Autenticación de usuarios:** acceso mediante inicio de sesión y registro.
- 📸 **Captura fotográfica:** toma fotografías directamente desde la aplicación.
- 📍 **Geolocalización:** registro de latitud y longitud de las evidencias.
- 📝 **Comentarios descriptivos:** añade observaciones de hasta 200 caracteres.
- 🖼️ **Galería de evidencias:** consulta las fotografías guardadas.
- 🔎 **Detalle de evidencias:** visualiza la información asociada a cada fotografía.
- 🗑️ **Administración de registros:** elimina evidencias cuando sea necesario.

## 💡 ¿Cómo funciona?

1. **Accede a la aplicación:** inicia sesión o crea una cuenta.
2. **Captura una fotografía:** utiliza la cámara desde la aplicación.
3. **Registra la ubicación:** asocia la evidencia con sus coordenadas GPS, si la ubicación está disponible.
4. **Agrega comentarios:** describe los detalles relevantes de la fotografía.
5. **Guarda la evidencia:** conserva el registro para consultarlo posteriormente.
6. **Consulta la galería:** revisa los registros y sus detalles cuando lo necesites.

- GPS y servicios de ubicación de Android

## ⚙️ Instalación

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Elhiu2308/Proyecto-modulo-8.git
   ```

2. Abre el proyecto en Android Studio.
3. Espera a que finalice la sincronización de Gradle.
4. Configura un dispositivo Android o emulador compatible.
5. Ejecuta la aplicación.

La aplicación puede requerir permisos de cámara y ubicación para habilitar las funcionalidades correspondientes. El acceso a estos recursos depende de los permisos concedidos por el usuario y de la configuración de Android.

No publiques credenciales, tokens ni archivos privados de configuración en el repositorio.
